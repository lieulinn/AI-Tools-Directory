# AI TOOLS LVARA — AI Tools Directory

AI TOOLS LVARA adalah web direktori direktori katalog alat AI berbasis web statis. Proyek ini memfasilitasi pencarian, penyaringan kategori, serta kategorisasi tools AI populer, terbaru, dan featured.

---

## Fitur Utama

- **Live Search**: Pencarian real-time berdasarkan nama dan deskripsi tools AI.
- **Category Filter Pills**: Filter cepat kategori (Writing, Image, Video, Coding).
- **Tab Categorization**: Pengelompokan berbasis status (All, Featured, Popular, New).
- **Modal Detail View**: Tampilan rincian informasi dan tautan langsung ke website AI.
- **Dark / Light Mode**: Pengubah tema warna antarmuka.

---

## Teknologi yang Digunakan

- **HTML5**: Struktur halaman direktori semantik.
- **CSS3**: Tata letak CSS Grid, Flexbox, dan variabel CSS tema.
- **JavaScript ES6+**: Array data lokal, fungsi pencarian real-time, dan manipulasi DOM.
